# BlueGlass AI Assistant UI

A responsive standalone web UI template for an AI Assistant / AI Agent workspace.

## Style
- White + blue glassmorphism
- Responsive desktop/tablet/mobile layout
- Soft gradients, translucent cards, blur, subtle shadows

## Included
- AI Assistant chat
- Model selector
- Quick prompts
- File attachment UI
- Voice input button
- AI Agent management
- Task queue / execution center
- Knowledge base
- Integrations
- Conversation history
- Analytics
- Settings
- Notifications
- Responsive navigation

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Customize
- Colors and glass effects: `style.css`
- UI interactions: `script.js`
- Page structure: `index.html`

This is a frontend template. Connect the chat send handler to your preferred AI API/backend to make it production-ready.
